# Prefabs

Production prefabs and prefab variants live here.

Place here:

- Player, enemy, weapon, projectile, arena, room, UI, VFX, and pickup prefabs
- Variants that reference approved third-party source assets

Do not place here:

- Raw third-party model packs
- Temporary scene-only objects
- Prefabs that depend on undocumented scene hierarchy

Rule:

- Prefabs should follow `25_PREFAB_AND_SCENE_CONTRACTS.md`.
