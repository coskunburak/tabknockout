# ScriptableObjects

Project-owned data configs live here.

Place here:

- Player, weapon, enemy, ability, chapter, room, wave, economy, reward, balance, and monetization configs
- Local defaults for systems that may later use remote config

Do not place here:

- Runtime save files
- Third-party imported assets
- Duplicated hardcoded balance tables

Naming:

- Asset filenames should be readable and stable.
- Config ids inside assets should use lowercase `snake_case`.
