# Scripts

Production C# scripts for Tap Knockout live here.

Place here:

- Runtime gameplay code
- Service abstractions
- UI controllers
- Config and save code
- Utility code that belongs only to this project

Do not place here:

- Third-party package source
- Unity tutorial scripts
- Real Ads, IAP, Analytics, or remote config SDK wrappers before approval
- Scene-only one-off scripts that hide production behavior

Naming:

- Use `TapKnockout.*` namespaces.
- Keep components focused and data-driven.
- Use ScriptableObject configs for tunable values.
