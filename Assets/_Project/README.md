# Tap Knockout Project Folder

This is the production-owned root for Tap Knockout game code, prefabs, configs, art variants, tests, scenes, and tools.

Place here:

- Game-authored assets and prefabs
- Production scripts under `Scripts/`
- ScriptableObject configs under `ScriptableObjects/`
- Editor tools under `Editor/Tools/`
- Project-specific tests under `Tests/`

Do not place here:

- Third-party source asset packs
- Unity generated folders
- Experimental imports without license review
- Direct copies of protected game content

Naming:

- Runtime code should use the `TapKnockout.*` namespace.
- Stable content/config ids should use lowercase `snake_case`.
