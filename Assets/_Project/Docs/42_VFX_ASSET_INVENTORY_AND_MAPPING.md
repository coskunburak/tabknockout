# VFX Asset Inventory And Mapping

Date: 2026-07-04

## Scope

This inventory supports the desktop survivor VFX integration pass. The goal is a rich, readable arena-survivor combat layer using assets already imported in the repository. Soulstone Survivors is a feel reference only; this mapping uses project-local third-party packs and project-owned catalog events.

## Not Used Intentionally

- Legacy `CFX2_Blood` and blood-heavy effects: avoided to keep the game readable and stylized.
- Demo scenes, demo UI, and camera/demo scripts from third-party packs: not gameplay assets.
- Rain, tornado, flamethrower, meteor-rain, and other long-loop effects: too noisy or expensive for frequent combat events.
- Large portal/door effects for normal hits: reserved for room/reward beats, not primary combat.
- Third-party scripts in demo folders: not referenced by runtime mapping.
- Pure material/mesh assets: catalog maps prefab-level effects so pooling and lifetimes are controllable.

## Risk Notes

- Some imported packs contain demo scripts and scene assets. Runtime catalog entries use prefabs only, and `PooledVFXSpawner` supports missing/broken components safely.
- VisualEffect Graph components are handled reflectively by the pooler, so the gameplay assembly does not take a compile dependency on the VFX Graph package.
- The spawn telegraph scene prefab remains a project-owned wrapper with `SpawnTelegraphMarker`; repair now adds the selected imported magic-circle child when available.
- The catalog can be regenerated from `Tools/Tap Knockout/VFX/Create Vertical Slice VFX Catalog`; missing third-party prefabs generate warnings but do not crash runtime.

## Readability Strategy

- Primary attacks stay warm, small, and short.
- Skills use larger slash/ring/ground silhouettes.
- Dash effects use flash/wind/blue impact cues.
- Enemy hits remain brief so hit flash and damage numbers stay readable.
- Elite and boss effects are larger, but reserved for spawn, phase, heavy attack, and death beats.
- Spawn/boss warnings use ground circles; hit/damage effects use sparks/bursts so danger is visually separate from player attacks.
- XP uses blue/green reward colors and short collection pulses.

## Performance Strategy

- Frequent effects are catalog pooled with small initial pool sizes for normal shots, enemy hits, dash hits, and pickup effects.
- Large effects have smaller pools and longer lifetimes.
- Projectile trails are parented to projectile transforms and released early when the parent is inactive to avoid stale trails after projectile pooling.
- Particle systems are stopped and cleared on pool return.
- VisualEffect-like components are restarted/stopped reflectively if present.
- Missing catalog definitions or missing prefabs warn once only when debug logging is enabled.
