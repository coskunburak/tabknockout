# Risk Register

## R1 Clone Risk
Risk: Too similar to Archero.  
Mitigation: Original art, UI, names, enemies, abilities, dash-impact identity.

## R2 Unity MCP Capacity Limit
Risk: MCP unavailable.  
Mitigation: No-MCP workflow, Editor scripts, manual Unity setup.

## R3 Scope Explosion
Risk: Too many systems before fun core.  
Mitigation: Vertical slice first.

## R4 Combat Not Fun
Risk: Movement/attack/dash lacks feel.  
Mitigation: Test combat first, add VFX/audio/shake early.

## R5 Economy Complexity
Risk: Too many currencies.  
Mitigation: Start with coins/gems/materials.

## R6 Monetization Hurts Retention
Risk: Too many ads/paywalls.  
Mitigation: Rewarded optional, interstitials later.

## R7 Performance
Risk: Too many enemies/projectiles/VFX.  
Mitigation: Pooling, URP optimization, device profiling.

## R8 Licensing
Risk: Unclear assets.  
Mitigation: Credits tracking, known sources only.

## R9 Poor FTUE
Risk: Players do not understand stop-to-attack/dash.  
Mitigation: Tutorial + analytics.

## R10 SDK Compliance
Risk: Privacy/ads/IAP issues.  
Mitigation: Compliance document before real SDKs.
