# Asset Pipeline and Art Direction

## Art Direction

- Stylized 3D
- Low-poly or clean mobile 3D
- Bright readable colors
- Clear silhouettes
- Clear projectiles and danger zones
- Portrait screen readability

## Sources

Recommended:

- Kenney
- KayKit
- Quaternius
- Mixamo
- Unity Asset Store
- Custom Blender later

## Licensing

Allowed:

- CC0
- Commercial-use allowed
- Paid asset with valid license
- CC-BY with credits

Forbidden:

- Ripped assets
- Fan art
- Trademarked characters
- Unknown license
- Copying existing game assets

## Folder Rules

```text
Assets/ThirdParty/KayKit/
Assets/ThirdParty/Quaternius/
Assets/ThirdParty/Mixamo/
Assets/_Project/Prefabs/
Assets/_Project/Art/Materials/
```

## Required Vertical Slice Assets

- Player model
- 3 enemy types
- Boss placeholder
- One weapon
- Room/arena tiles
- Projectile VFX
- Hit VFX
- Dash VFX
- Ability icons
- UI buttons/cards
- SFX/music placeholders

## Animation

Player:

- Idle
- Run
- Attack
- Dash
- Hit
- Death
- Victory

Enemy:

- Idle
- Move
- Attack
- Hit
- Death
- Special

Mixamo settings:

```text
FBX for Unity
30 FPS
Keyframe Reduction: None
With Skin first model
Without Skin for extra animations
```
