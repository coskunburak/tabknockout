# Product Vision

## Vision

Tap Knockout is a production-level commercial mobile roguelite action game. It combines the readability of Archero-style room progression with a distinct dash-impact combat identity.

## Target Audience

Primary:

- Mobile roguelite players
- Archero-like action players
- Casual action players
- Gear/meta progression players

Secondary:

- Players motivated by daily rewards, missions, chests, events, and long-term upgrades

## Product Positioning

Genre:

```text
Portrait mobile action roguelite / hybrid-casual RPG
```

Commercial model:

- Free-to-play
- Rewarded ads
- IAP bundles
- No Ads purchase
- Battle pass later
- Events/liveops later

## Differentiation

The game must be original. Its unique angle:

```text
Dash-impact combat: dash can deal damage, knock back, interrupt, trigger shockwaves, chain abilities, and create combo moments.
```

## Core Experience

A player should understand quickly:

- Drag to move
- Stop/position to attack
- Dash to survive or strike
- Clear rooms
- Choose abilities
- Upgrade between runs

## Production Goals

- Soft-launch capable architecture
- Analytics-ready
- Remote config-ready
- Monetization-ready
- Scalable content pipeline
- Store-compliant privacy/ads/IAP structure
