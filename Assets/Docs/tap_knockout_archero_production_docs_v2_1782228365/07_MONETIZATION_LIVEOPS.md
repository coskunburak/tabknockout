# Monetization and LiveOps

## Philosophy

Commercial but ethical.

- Rewarded ads optional.
- IAP accelerates/customizes.
- No forced ads in FTUE.
- No real SDKs before privacy/compliance setup.

## Rewarded Ads

Initial placements:

- Revive once per run
- Double run rewards
- Free chest
- Extra ability reroll
- Daily bonus

## Interstitial Ads

Use later and cautiously:

- After failed run
- After N runs
- Never during combat
- Not before retention validation

## IAP Products

Possible:

- Starter Pack
- No Ads
- Gem Pack
- Growth Fund
- Battle Pass
- Event Bundle

Vertical slice:

- Stubs/configs only.
